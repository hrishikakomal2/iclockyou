# I Clock You (test build)

A shared clock for your day, and for two. Notes, reminders, alarms and schedule in **My Space**, plus **Our Space** when you Mingle with a partner.

Open the site on your phone and use *Add to Home Screen*. See `HOW-TO-PAIR.txt` for pairing two phones with a code.

This is an early test build. Data stays on each phone.
